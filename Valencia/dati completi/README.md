# Valencia — dati completi

Struttura organizzata dei file attualmente presenti nel repository.

- `config/`: configurazione città e timeline.
- `documentazione/`: README e limiti metodologici.
- `metadati/`: cronologia e registro delle fonti.
- `audit/`: report di validazione.
- `dati_generati/`: destinazione prevista per i dataset elaborati.
- `sorgenti_originali/`: destinazione prevista per i dati sorgente grezzi.

## Stato dell'inventario

I file di configurazione, documentazione, metadati e audit sopra elencati sono stati copiati qui dai file già presenti in `Valencia/`.

**I dataset elaborati e le sorgenti originali non risultano ancora caricati in questa cartella GitHub.** Le cartelle `dati_generati/` e `sorgenti_originali/` non contengono ancora i dati effettivi; non considerare questa cartella completa finché non saranno presenti i file di dati.
